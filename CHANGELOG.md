# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [bso5 0.4.0] — 2026-11-01

### Добавлено

- `computed(fn)` — производное значение: пересчитывается от зависимостей и уведомляет только при реальном изменении результата.
- `mount(target, view)` → `{ node, dispose }` — монтирование и полный снос вью. Принимает танку; готовый узел снимается только по привязкам.
- `createScope()` / `dispose(scope)` / `runInScope(scope, fn)` / `onScopeDispose(fn)` — владение эффектами поддерева.
- `batch(fn)` — одна волна эффектов и слушателей на группу записей; `untrack(fn)` — чтение без зависимости.
- `effect(fn, { onError })` и `setEffectErrorHandler(fn)` — ошибки эффектов больше не уходят только в `console.error`.
- `ref={el => …}` в `h()` и JSX; `on*Capture` ставит обработчик в фазу перехвата.
- `parseEventProp(key)` и `applyAttr(el, key, value)` в публичном API.

### Изменено

- `<For>` и `<Show>` владеют эффектами своего поддерева: перерисовка, смена ветки и удаление ключа останавливают эффекты и освобождают DOM-привязки (до этого подписки накапливались: 3 → 18 за пять перерисовок).
- Keyed `<For>` перемещает только узлы не на своём месте: обновление «тот же порядок, новый массив» на 10 000 элементов — 2 348 мс → 1,8 мс (jsdom).
- `<Show>`: ветка-танка снимается при скрытии; готовый узел кешируется и держит привязки (перепривязать его нельзя) — передавайте танку, если нужен настоящий снос.
- `Reactive` больше не оборачивает `Map`, `Set`, `WeakMap`, `WeakSet`, `Promise`, `Date`, `RegExp`, `Error`, `ArrayBuffer`/`TypedArray`, `Blob`, `AbortController`, `FormData`, `URL` — методы этих объектов бросали `TypeError: called on incompatible receiver`.
- `Attrs.style` принимает числа (рендерятся как `px`), значения `style` могут быть `$()`; обработчики в `h()` сохраняют тип `Event`.
- Трекинг ограничен строковыми ключами: символьные обращения не попадают в зависимости.
- `onDoubleClick` срабатывает как `dblclick` (раньше — молча никогда); `<select>.value` применяется после появления `<option>`.
- Размер: 3,48 → 4,2 kB min+gzip.

### Исправлено

- `npm install` в чистом клоне: в `package-lock.json` было 48 записей без поля `version`, из-за чего установка падала `Invalid Version:`, а `npm ci` был невозможен.
- Строгая типизация на чистой установке: `@types/node` объявлен явно (падало `TS2688`).
- `<For>` без `key` больше не оставляет подписки и «мёртвые» эффекты снятых узлов.

### Инфраструктура

- `sourceMap` и `declarationMap` в `dist`; сборка компонентов берёт типы соседнего пакета из `dist` (`TS6059` при `rootDir`).
- `publishConfig.access = public`, `repository` / `homepage` / `bugs` в обоих пакетах.
- `npm run pack:check` — проверка состава tarball (`npm pack --dry-run`).
- Порог покрытия в `vitest.config.ts` (88/84/90/92 %); фактически 93.7/88.3/93.9/97.7 %.
- CI: матрица Node 22/24, дым-бенч (`BENCH_SIZES=1000`), `pack:check`, отдельная job с покрытием.

### Документация

- `docs/API.md` — полный справочник API: сигнатуры, семантика, крайние случаи, ограничения.
- `docs/API.en.md` и `docs/GUIDE.en.md` — те же справочник и рецепты по-английски; `llms-full.en.txt` — английская версия «всё одним файлом».
- `docs/GUIDE.md` — рецепты по задачам и таблица «симптом → причина → что делать».
- `docs/README.md` — навигация: что читать под какую задачу, правила поддержки документации.
- `llms.txt` и `llms-full.txt` — карта документации и вся документация одним файлом для LLM;
  `npm run docs:llm` пересобирает, `npm run docs:check` сверяет в CI.
- `npm run docs:check` проверяет и заголовки-якоря (по алгоритму GitHub), а не только файлы.
- `docs/PROPS.md` — таблицы пропсов, сгенерированные из TypeScript-интерфейсов (`npm run docs:props`): типы и обязательность берутся из кода, описания — из JSDoc.
- `docs/topics/*` — справочник, нарезанный на 14 коротких тем по 0.3–2 kB (`npm run docs:topics`), для точечного чтения вместо загрузки всего API.
- `packages/bso5-components/tests/recipes.test.tsx` — исполняемые рецепты: итоговый DOM каждого рецепта `GUIDE` зафиксирован тестом.
- `llms.txt` сокращён до одной страницы с прямой рекомендацией, что читать.
- `$()` на вложенном прокси: значение резолвится относительно переданного объекта (раньше `$(row, x => x.title)` возвращал `undefined`, потому что путь считался от корня). Замена слота родителя у вложенной привязки не отслеживается — привязывайтесь от корня; `watch()` с аксессором ведёт себя так же.
- Компилируемые сниппеты `docs/snippets/*` (включая рецепты) входят в `typecheck`.
- `$()` получил перегрузки и сохраняет тип значения (`BoundValue<T>` вместо `BoundValue<unknown>`).

## [bso5-components 0.2.0] — 2026-11-01

### Изменено (ломающие)

- `rowKey(row)` вместо `rowKey(row, index)`: индекс менялся при каждой сортировке, и keyed-режим превращался в полную пересборку.
- `Tree.nodeKey(node, path)` теперь действительно задаёт ключ раскрытия (раньше проп не вызывался).
- README приведён к коду: `header` вместо выдуманного `label`, обязательный `sort`, класс `match` вместо `highlight`, реальные сигнатуры.

### Добавлено

- `labels` у `Grid` и `Tree`: плейсхолдер, aria-метки, направление сортировки, префиксы счётчиков; `Tree.labels` — ещё и подписи кнопок.
- `searchDebounce` / `searchDebounceMinItems` — задержка поиска настраивается (по умолчанию 120 мс от 200 элементов, `false` отключает).
- `Tree.showExpandAll` — кнопки «развернуть всё» / «свернуть всё».
- Доступность: `aria-sort` у активной колонки, `aria-expanded` у групп и узлов, `role="tree"/"treeitem"/"group"`, клавиатура (Enter/Space, ArrowRight/ArrowLeft в дереве, ArrowUp/ArrowDown, Enter/Space в группе грида), `aria-label` у полей поиска.
- Дерево: одна точка входа по Tab, навигация стрелками, возврат фокуса после перерисовки.

### Исправлено

- Стрелка группы не менялась в keyed-режиме (оставалась `▾` после схлопывания).
- `initialSort.dir` игнорировался контролом направления; клик по заголовку теперь обновляет и его.
- Фильтр дерева ищет и по `meta`.
- Размер: 1,95 → 2,5 kB min+gzip.

# bso5

> Реактивный DOM без лишнего веса — крошечная библиотека TypeScript с состоянием Signal/Reactive и первоклассной поддержкой JSX. Без фреймворка.

**~3.4 kB min+gzip** · ноль зависимостей · строгий TypeScript · 121 тест

[English version](./README.en.md)

```tsx
import { Reactive, $, For } from 'bso5';

const state = new Reactive({ user: { name: 'ann' }, items: ['a', 'b'] });

function App() {
  return (
    <main>
      <h1>Привет, {$(state.value, x => x.user.name)}!</h1>
      <ul>
        <For each={() => state.value.items}>
          {(item, i) => <li>{i + 1}: {item}</li>}
        </For>
      </ul>
    </main>
  );
}

document.getElementById('app')!.appendChild(<App />);
```

Без JSX? Используйте фабрику `h()` напрямую — всё остальное работает идентично.

## Основные концепции

| Экспорт | Назначение |
| --- | --- |
| `Signal<T>` / `signal(v)` | Атомарное реактивное значение: чтение/запись `.value`, `.peek()`, `.update()`, `.subscribe()` |
| `Reactive<T>` | Глубокий реактивный прокси над обычным объектом с подписками на пути свойств |
| `effect(fn)` | Автотрекаемое вычисление: перезапускается при изменении любого прочитанного значения |
| `watch(src, path, cb)` | Ручная подписка на `Signal` или путь свойства `Reactive` |
| `$(src, path?)` | Создаёт **привязанное значение** для детей и атрибутов JSX |
| `<For each={…}>` | Реактивный рендер списка; необязательный `key` включает переиспользование DOM-узлов |
| `<Show when={…}>` | Реактивный условный рендер с необязательным `fallback` |
| `h(tag, attrs, ...kids)` | Универсальная фабрика элементов (сильно типизирована по HTML-тегам) |
| `releaseBindings(root)` | Останавливает реактивные DOM-привязки отсоединённого поддерева |
| `Fragment` | JSX-фрагмент; `bso5/jsx-runtime` — точки входа для automatic JSX |

### Signal

```ts
import { signal, effect } from 'bso5';

const name = signal('ann');

effect(() => {
  console.log(name.value); // 'ann', затем 'bob'
});

name.value = 'bob';   // уведомляет подписчиков и эффекты
name.peek();          // 'bob' — чтение без трекинга
name.update(v => v + '!');  // обновление от текущего значения (нетрекируемое чтение)
```

### Reactive

```ts
import { Reactive, watch } from 'bso5';

const state = new Reactive({
  user: { name: 'ann', address: { city: 'Rome' } },
  tags: ['a', 'b'],
});

// Следить за вложенным путём — аксессором или строкой 'user.address.city'.
watch(state.value, x => x.user.address.city, () => { /* … */ });
// Индексная нотация тоже работает: 'rows.1.done' аксессором или строкой.
watch(state.value, x => x.rows[1].done, () => { /* … */ });

state.value.user.address.city = 'Milan';  // запускает вотчер
state.value.user = { name: 'bob', ... };  // вложенные пути перепривязываются автоматически
state.value.tags.push('c');               // массивы поддерживаются (length трекается)
```

`.value` возвращает реактивное дерево прокси; `.target` открывает сырой объект
(чтения/записи там нетрекируемые). `dispose()` останавливает все подписки и
трекинг эффектов — привязки затихают, а чтения/записи через прокси продолжают
работать как обычный сквозной проход.
### Привязанные значения: `$()`

`$()` — мост между состоянием и разметкой. Используйте его как **ребёнка JSX**
или **значение атрибута**, и он держит DOM в актуальном состоянии:

```tsx
<p>Счёт: {$(state.value, x => x.count)}</p>
<input value={$(state.value, x => x.name)} disabled={$(state.value, x => x.busy)} />
<div style={{ color: $(state.value, x => x.color) }}>цветной</div>
```

- `$()` принимает `Signal` (`$(countSignal)`) или прокси `Reactive` + аксессор пути.
- Аксессор пути должен быть **простой чистой цепочкой свойств** (`x => x.user.name`;
  `x => x.items[0].title` — индексная нотация поддерживается). Он *выполняется*
  один раз на подписку для трассировки пути, поэтому не должен иметь побочных
  эффектов. Вычисляемые выражения (`x => x.count + 1`) и вызовы методов
  отвергаются. Оборачивайте их в `effect()`.
- Привязанные значения нельзя интерполировать в шаблонные строки —
  `label={`+${$(...)}`}` отрендерит `[object Object]`. Привязывайте сам
  атрибут/ребёнка, а не строку вокруг него.

### Списки и условия: `<For>` и `<Show>`

JSX-выражения вычисляются **один раз** при монтировании. Для реактивных списков
и условий используйте `<For>` / `<Show>` — они рендерят между невидимыми
комментариями-анкорами (без обёрток, без ре-рендера родителя):

```tsx
import { For, Show } from 'bso5';

<ul class="history">
  <For each={() => state.value.history}>
    {(value, i) => <li>шаг {i + 1}: {value}</li>}
  </For>
</ul>

<Show when={() => state.value.count > 10}>
  <p class="alert">Слишком много!</p>
</Show>
```

`each` / `when` принимают обычное значение, танк `() => value` (перечитывается
и автотрекается), `Signal` или привязанное значение `$()`. По умолчанию `<For>`
перерисовывает весь список при изменении — держите функции элементов дешёвыми;
для тонких привязок используйте `$()` внутри них.

Передайте `key`, чтобы включить **keyed-реконсиляцию**: существующие DOM-узлы
переиспользуются и перемещаются (`insertBefore`) вместо пересоздания, сохраняя
фокус, каретку, выделение текста, состояние медиа и CSS-transition'ы при
пересортировках. Семантика обычная React/Solid:

- ключ идентифицирует элемент — **пока ключ в списке, узлы элемента не
  перерисовываются**: привязывайте поля элемента через `$()` внутри
  render-функции, а не свежими данными элемента;
- отрисованный `index` фиксируется при первом рендере и не обновляется при
  пересортировке — привязывайте его через `$()`, если нужен живой индекс;
- ключи должны быть уникальными: дубликаты схлопываются в одну группу узлов.

```tsx
<For each={() => state.value.rows} key={(row: Row) => row.id}>
  {(row) => <li>#{row.id} <input value={$(row, x => x.name)} /></li>}
</For>
```
### `effect()` для полного контроля

Когда нужно то, чего декларативные компоненты не покрывают — canvas, сторонние
виджеты, ручной DOM — используйте `effect()`. Он трекает каждый `Signal` и
каждое свойство `Reactive`, прочитанное внутри:

```tsx
import { effect, h } from 'bso5';

const list = h('ul', { class: 'history' });
effect(() => {
  // перезапускается на любое изменение прочитанного
  list.replaceChildren();
  for (const item of state.value.history) list.append(h('li', {}, `${item}`));
});
```
